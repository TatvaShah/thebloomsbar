# The Blooms Bar

Marketing site for the Kerman, California florist [@_thebloomsbar_](https://www.instagram.com/_thebloomsbar_/). Luxury bouquets, delivery, English or Spanish notes, closed Sundays. Orders are Instagram DMs. Nothing is charged on the site.

```bash
npm install
npm run dev -- --port 4317
```

Build a bouquet at `/build`. The last step copies a note and opens the Instagram DM.
